# 📚 Web Project Library – Sprint 2

Este projeto foi desenvolvido como parte da Sprint 2 do curso Web Development da TripleTen. O objetivo era criar o cabeçalho de uma página web utilizando HTML e CSS sem frameworks, aplicando boas práticas de semântica, responsividade e nomeação de classes com a metodologia BEM.
Foi a primeira experiência prática na construção de um layout real.

**🎯 Objetivo do Projeto**

Aprender a construir o cabeçalho de uma página web estática com HTML5 e CSS3, utilizando estrutura semântica, Flexbox para posicionamento dos elementos e nomeação de classes seguindo a metodologia BEM.

**✅ Resultado**

A estrutura do cabeçalho foi criada com sucesso, incluindo logo, menu de navegação e design responsivo. As instruções da plataforma foram seguidas cuidadosamente, com atenção aos nomes de classes exigidos e organização do código.
O projeto serviu como base para os próximos passos no front-end e me ajudou a entender como os blocos de layout se conectam.

**🛠 Tecnologias Utilizadas**

- HTML5  
- CSS3  
- Flexbox  
- Metodologia BEM  
- Git e GitHub  

**⚙️ Funcionalidades**

- ✅ Cabeçalho com logo e menu de navegação  
- ✅ Layout responsivo com Flexbox  
- ✅ Tags semânticas utilizadas corretamente  
- ✅ Nomeação de classes com BEM  

**🚀 O que aprendi com esse projeto**

- Aplicar estrutura HTML semântica para páginas web  
- Utilizar Flexbox para posicionamento de elementos  
- Nomear classes com a metodologia BEM   

**🔧 Melhorias Futuras**

- Adicionar interações com JavaScript no menu  
- Tornar o menu acessível com suporte a teclado
